## 📖 About Project 115 - Despair

**Project 115 - Despair** is one of the most ambitious and celebrated total conversions in the Doom modding community. Created by developer **Fabysk**, the project faithfully translates the iconic mechanics, atmosphere, and gunplay of **Treyarch's Call of Duty: Zombies** into the flexible and lightning-fast **GZDoom (UDMF)** engine.

Featuring a full-length, cinematic horror story campaign, authentic survival mode maps (including legendary recreations of *Nacht der Untoten*, *Nuketown Zombies*, and *Der Riese*), round-based horde scaling, Pack-a-Punch upgrades, dynamic perk-a-cola machines, and a deep arsenal of 40+ authentic weapons, *Project 115* stands as a monumental milestone of Doom engine engineering.

This repository exists as an **open-source digital preservation archive**, decomposing the monolithic 511MB binary WAD into clean, human-readable source components, decompiled ACS scripts, lossless textures, audio samples, and automated build tooling.

## ⚙️ Core Gameplay Mechanics

### 1. Economy & Point Generation
- **Bullet Hit**: +10 Points
- **Torso / Limb Kill**: +60 Points
- **Headshot Kill**: +100 Points
- **Melee / Knife Kill**: +130 Points
- **Window Barrier Repair**: +10 Points per plank (up to max round limit)

### 2. Perk-a-Cola System
Custom sound jingles, 3D animated vending machines, and persistent stat alterations:
- **Juggernog** (2500 pts): Increases player maximum health from 100 to 250 HP.
- **Speed Cola / Swift** (3000 pts): 50% faster reload speeds and rapid weapon handling.
- **Quick Revive** (500 pts Solo / 1500 pts Co-op): Auto-revival with temporary Mustang & Sally pistols in Solo; 3x faster team revive in multiplayer.
- **Double Tap / Double Shot** (2000 pts): 33% increased fire rate and split-bullet damage multipliers.

### 3. Pack-a-Punch (PAP)
Deposit any base weapon into the PAP machine (5000 pts) for:
- Doubled or tripled damage output.
- Expanded magazine capacity and reserve ammo.
- Laser projectile conversions, explosive impacts, or alternate firing modes.
- Custom Pack-a-Punch glowing weapon finish and unique firing sounds.

### 4. Power-Up Drops
Random drops from fallen zombies:
- 💣 **Nuke**: Instantly obliterates all active zombies on the map and awards +400 points to all players.
- 📦 **Max Ammo**: Fully replenishes reserve ammunition for all held weapons.
- ⚡ **Insta-Kill**: Any attack (bullet, knife, grenade) instantly kills any normal zombie for 30 seconds.
- 💰 **Double Points**: All points earned are multiplied by 2x for 30 seconds.
- 🔨 **Carpenter**: Instantly repairs all window barriers across the entire map (+200 points).
- 🏷️ **Fire Sale**: Reduces all Mystery Box spins to 10 points for 30 seconds.

## 🔨 How to Build / Repack

The repository includes `build_wad.py`, an automated Python tool that can compile the source tree into either a classic monolithic Doom PWAD or a modern GZDoom PK3 archive:

### 1. Build Standard Monolithic PWAD (`Project115.wad`)
```bash
python build_wad.py
```
*Outputs `Project115.wad` (~511 MB), playable in any standard UDMF-compatible Doom engine.*

### 2. Build Modern GZDoom Archive (`Project115.pk3`)
```bash
python build_wad.py --pk3
```
*Outputs `Project115.pk3` (~440 MB compressed zip), ideal for fast loading and web source ports.*

### 3. Build Both Formats Simultaneously
```bash
python build_wad.py --format both
```

### 4. Running with GZDoom Desktop
```bash
gzdoom -iwad doom2.wad -file Project115.pk3
# or
gzdoom -iwad doom2.wad -file Project115.wad
```
